# OpenAI Agent Plugins package

This generated P-ASES package contains portable Agent Plugins metadata at `plugin.json`, the canonical 16 Skills under `skills/`, shared standards/templates, and the local `p_ases` runtime. Register `https://github.com/puchinya/ai-agent-workflow` as a marketplace in Codex, then install `p-ases`. The generated `.agents/plugins/marketplace.json` entry uses `./dist/openai`, resolved inside the marketplace checkout. Refresh the marketplace in Codex after repository updates.

Marketplace installation reads the GitHub repository snapshot; it does not download a Release asset. Use the versioned OpenAI Release ZIP and `SHA256SUMS` when you need a pinned or offline manual install.

To use the CLI from a consumer checkout, install this directory with `python -m pip install /path/to/dist/openai`, then run `python -m p_ases --help`. `python -m p_ases project status` reads an existing profile; it does not initialize or change one. The source of truth is `workflow/`, `runtime/p_ases/`, and this adapter. Run `python tools/build_dist.py` from the repository root after editing canonical files.
