<a id="test-purpose"></a>
## 1 Test purpose

Define reproducible conditions and expected results independently of implementation details.

<a id="test-conditions-and-oracles"></a>
## 2 Test conditions and oracles

<a id="tst-dist-001"></a>
<a id="tst-dist-001-openai-package-boundary"></a>
### 2.1 TST-DIST-001 OpenAI package boundary

**Setup and action:** Build the OpenAI package and validate its root manifest and marketplace target.

<a id="ora-dist-001"></a>
<a id="ora-dist-001-expected-result"></a>
#### 2.1.1 ORA-DIST-001 Expected result

Only the approved OpenAI schema, skill paths, and repository-contained source are present.

<a id="tst-dist-002"></a>
<a id="tst-dist-002-claude-package-boundary"></a>
### 2.2 TST-DIST-002 Claude package boundary

**Setup and action:** Build the Claude package and validate nested manifest and marketplace metadata.

<a id="ora-dist-002"></a>
<a id="ora-dist-002-expected-result"></a>
#### 2.2.1 ORA-DIST-002 Expected result

The Claude plugin manifest and one repository-contained package source are present and names match.

<a id="tst-dist-003"></a>
<a id="tst-dist-003-antigravity-package-boundary"></a>
### 2.3 TST-DIST-003 Antigravity package boundary

**Setup and action:** Build the Antigravity package and validate its local/manual manifest.

<a id="ora-dist-003"></a>
<a id="ora-dist-003-expected-result"></a>
#### 2.3.1 ORA-DIST-003 Expected result

Only allowed schema properties and resources are present; no marketplace capability is claimed.

<a id="tst-dist-004"></a>
<a id="tst-dist-004-deterministic-generation-and-check"></a>
### 2.4 TST-DIST-004 Deterministic generation and check

**Setup and action:** Build twice from identical canonical sources and alter one generated byte before check.

<a id="ora-dist-004"></a>
<a id="ora-dist-004-expected-result"></a>
#### 2.4.1 ORA-DIST-004 Expected result

Independent builds are byte-identical; check reports drift without writing or repairing files.

<a id="tst-dist-005"></a>
<a id="tst-dist-005-release-asset-contract"></a>
### 2.5 TST-DIST-005 Release asset contract

**Setup and action:** Package a valid stable tag and invalid/version-mismatched tags in temporary directories.

<a id="ora-dist-005"></a>
<a id="ora-dist-005-expected-result"></a>
#### 2.5.1 ORA-DIST-005 Expected result

Valid output contains exactly the named ZIPs and checksum file; invalid input creates no assets.

<a id="tst-dist-006"></a>
<a id="tst-dist-006-observable-package-behavior"></a>
### 2.6 TST-DIST-006 Observable package behavior

**Setup and action:** Inspect package path lists and run each independent host validator.

<a id="ora-dist-006"></a>
<a id="ora-dist-006-expected-result"></a>
#### 2.6.1 ORA-DIST-006 Expected result

Each host package is independently inspectable and includes only its required shared resources.

<a id="tst-dist-007"></a>
<a id="tst-dist-007-credential-and-network-boundary"></a>
### 2.7 TST-DIST-007 Credential and network boundary

**Setup and action:** Run build and validation with fake/no network access and inspect generated outputs.

<a id="ora-dist-007"></a>
<a id="ora-dist-007-expected-result"></a>
#### 2.7.1 ORA-DIST-007 Expected result

No credentials or consumer state appear and no external schema fetch is needed.

<a id="tst-dist-008"></a>
<a id="tst-dist-008-failure-and-publication-boundary"></a>
### 2.8 TST-DIST-008 Failure and publication boundary

**Setup and action:** Simulate schema error, drift, failed matrix, and GitHub release lookup/upload errors.

<a id="ora-dist-008"></a>
<a id="ora-dist-008-expected-result"></a>
#### 2.8.1 ORA-DIST-008 Expected result

Failures stop publication without source/tag mutation; retry can converge on expected assets.
